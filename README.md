# SimpleEssenceCache

A lightweight, file-based caching class for PHP.

This class allows you to easily store, retrieve, and manage cached data using the local file system.

## Features

- Store data with expiration
- Retrieve and validate cached data
- Check for cache existence
- Delete specific or expired cache entries
- Clear all cache files
- JSON-based file format
